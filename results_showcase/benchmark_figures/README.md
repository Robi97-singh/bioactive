# Benchmark Comparison Figures

Publication figures for the frozen-backbone bioactivity benchmark, styled after the two
most important plots of Fredin Haslum et al. (*Nature Communications* 15:3470, 2024): the
per-assay ROC-AUC boxplot (their Fig 1c) and the model comparison with Friedman + Nemenyi
statistical testing (their Fig 2a). All results are on JUMP-CP source_11, 29 assays, 6-fold CV.

Generated by `make_benchmark_figures.py` (in the repo root), which reads each arm's
`cv_per_assay.csv` and produces the figures below plus the statistics CSVs.

## Files

| File | What it is |
|------|-----------|
| `fig_A_per_assay_boxplot.png` | Per-assay ROC-AUC distribution, one box per backbone (29 assays) |
| `fig_B_model_comparison.png` | Backbones ranked, with Friedman test + Nemenyi post-hoc — the headline figure |
| `fig_C_resolution.png` | Resolution effect (224 vs 448) for the multi-resolution backbones |
| `nemenyi_pvalues.csv` | Pairwise significance matrix |
| `benchmark_summary.csv` | Mean / median / std per arm |

## Results

| Backbone (frozen @224) | Regime | Mean ROC-AUC |
|------------------------|--------|--------------|
| **Cell-DINO** | frozen probe | **0.593** |
| DINOv2-Base | frozen probe | 0.580 |
| BiomedCLIP | frozen probe | 0.577 |
| ResNet50 | fine-tuned | 0.664 |

Friedman across the four models: chi2 = 45.46, p = 7.4e-10 (highly significant).

Nemenyi pairwise (bold = significant at 0.05):

| Comparison | p-value | Significant |
|-----------|---------|-------------|
| **Cell-DINO vs DINOv2** | **0.012** | **yes** |
| Cell-DINO vs BiomedCLIP | 0.054 | borderline (n.s.) |
| DINOv2 vs BiomedCLIP | 0.957 | no |
| **ResNet vs Cell-DINO** | **0.017** | **yes** |
| **ResNet vs DINOv2** | **<0.001** | **yes** |
| **ResNet vs BiomedCLIP** | **<0.001** | **yes** |

**Headline findings:**
1. Domain-matched pretraining (Cell-DINO, trained on Cell Painting) **significantly** beats generic ImageNet (DINOv2) — with a smaller model.
2. Full fine-tuning (ResNet) **significantly** beats every frozen backbone — frozen features leave performance on the table.
3. Biomedical pretraining (BiomedCLIP) is **statistically indistinguishable** from generic ImageNet (DINOv2) — "biomedical" is not the same as domain-matched.

## Design decisions (why the figures are structured this way)

These choices are deliberate; the figures are not simply "everything plotted together."

**1. Figure B (the headline comparison) is 224-only, by design.**
The main backbone comparison uses all four models at a single matched resolution (224). This
isolates the backbone question ("which pretraining is best?") from the resolution question.
Mixing 224 and 448 variants into the ranking would confound backbone with resolution and make
the Friedman/Nemenyi comparison uninterpretable. Resolution is handled separately in Figure C.

**2. 448 exists only for the DINO-family backbones.**
Figure C compares 224 vs 448 for Cell-DINO, DINOv2, and the fine-tuned ResNet — the only
backbones that support genuine multi-resolution inference.

**3. BiomedCLIP (and CLIP) are 224-locked — no 448 arm.**
Their vision wrappers hard-downsample any input to 224 internally, and they use fixed 224px
positional embeddings. A "448" run would be silently downsampled back to 224 (an identical
result), and a genuine 448 would require positional-embedding surgery plus off-distribution
extrapolation of a CLIP image-text projection — confounding resolution with architectural
artifacts. BiomedCLIP is therefore evaluated at 224 only, and excluded from Figure C.

**4. The resolution effect is model-dependent (a finding, not an omission).**
Figure C shows resolution helps the fine-tuned ResNet (+1.5 pts) and frozen DINOv2 (+0.9 pts,
pretrained at 224) but does nothing for frozen Cell-DINO (pretrained at 128px, already
extrapolating its position embeddings). A frozen backbone benefits from higher resolution only
when the new resolution stays close to its pretraining resolution.

**5. Individual-assay ROC curves (the reference paper's Fig 1d) are not included.**
The pipeline saved per-assay AUC scalars, not per-sample predictions, so drawing ROC curves
would require a re-inference pass to store prediction arrays. The per-assay boxplots (Fig A)
already convey per-assay discrimination, so this was deprioritised; it remains available as a
follow-up if a specific assay's ROC curve is wanted for illustration.
