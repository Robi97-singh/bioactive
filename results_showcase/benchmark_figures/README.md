# Benchmark Comparison Figures

Publication figures for the backbone bioactivity benchmark, styled after the two most important
plots of Fredin Haslum et al. (*Nature Communications* 15:3470, 2024): the per-assay ROC-AUC
boxplot (their Fig 1c) and the model comparison with Friedman + Nemenyi statistical testing
(their Fig 2a). All results are on JUMP-CP source_11, 29 assays, 6-fold CV (LoRA: 3-fold CV,
see note). Generated by `make_benchmark_figures.py` and `make_adaptation_figure.py`.

## Files

| File | What it is |

| `fig_B_model_comparison.png` | Frozen backbones + ResNet ranked, Friedman + Nemenyi -- headline figure |

| `benchmark_summary.csv` | Mean / median / std per arm |

## Findings

1. **Domain-matched pretraining wins.** Cell-DINO (pretrained on Cell Painting) significantly beats generic ImageNet DINOv2-Base (Nemenyi p=0.0044) and DINOv2-Large (p=0.0139) -- with a smaller model in both cases.
2. **Scale alone does not help, frozen.** DINOv2-Large (304M params) is statistically indistinguishable from DINOv2-Base (86M params) -- p=0.9974 -- despite a 3.5x increase in parameters, holding architecture and pretraining domain fixed. This isolates parameter count as not the active ingredient behind CLIP-L's earlier scale advantage; pretraining data volume/diversity is the more likely driver.
3. **"Biomedical" is not domain-matched.** BiomedCLIP is statistically indistinguishable from generic ImageNet DINOv2-Base (p=0.9938) and DINOv2-Large (p=1.0000) -- nominal biomedical relevance does not help. It is, however, now significantly worse than Cell-DINO (p=0.0181), reinforcing that domain-matched pretraining specifically (not just "biomedical" branding) is what matters.
4. **Resolution is model-dependent.** It helps fine-tuned ResNet (+1.5 pts) and frozen DINOv2 (+0.9 pts, pretrained at 224) but not frozen Cell-DINO (pretrained at 128px). A frozen backbone benefits from higher resolution only when it stays close to its pretraining resolution.
5. **Cheap adaptation recovers over half the gap.** LoRA (2.4% of parameters trainable), now validated on 3 folds (0.6082, 0.6233, 0.6456; mean 0.626), reaches above every frozen backbone, recovering ~55% of the frozen->fine-tuned gap over DINOv2-Base -- notably higher than an earlier single-fold estimate (~33%), since fold-to-fold variance for LoRA (std ~0.015-0.019) is wider than for the frozen arms (std ~0.006-0.007). A full 6-fold run is in progress to tighten this further.
6. **Fine-tuning remains the strongest option, though the margin over domain-matched frozen features is narrower than it first appeared.** ResNet significantly beats DINOv2-Base, DINOv2-Large, and BiomedCLIP (all p<0.001), and sits above LoRA -- but the gap to Cell-DINO specifically is no longer statistically significant at the 5-arm correction (p=0.0605, borderline).

## Design decisions

**1. Figure B is 224-only and frozen + ResNet, by design.** The rigorous statistical comparison
uses a single matched resolution (224) so the Friedman/Nemenyi test isolates the backbone
question from resolution. Mixing 224/448 variants would confound the two.

**2. LoRA is shown in Figure D, not Figure B.** LoRA training is NFS-I/O-bound (~1 h/epoch), so
folds are validated incrementally rather than all six launched at once; 3 of 6 folds are
complete as of this writing (folds 1/3/5 in progress), whereas the frozen and fine-tuned arms
are already 6-fold means. To avoid mixing a partial-fold estimate with 6-fold means in one
statistical plot, LoRA appears in the separate adaptation-spectrum figure (Fig D), which is a
regime comparison rather than a CV significance test. The fold count is noted directly on the
figure and updates automatically as more folds land.

**3. 448 exists only for the DINO-family backbones.** BiomedCLIP and CLIP hard-downsample input
to 224 internally and use fixed 224px positional embeddings, so a genuine 448 arm is not
possible without positional-embedding surgery and off-distribution extrapolation of a CLIP
image-text projection. They are evaluated at 224 only and excluded from Figure C. DINOv2-Large's
448 arm is in progress and will be added to Figure C once complete.

**4. The resolution effect is a finding, not an omission** -- see finding 4.

**5. Individual-assay ROC curves (the reference paper's Fig 1d) are not included for most arms.**
The pipeline saved per-assay AUC scalars, not per-sample predictions, so drawing ROC curves
would need a re-inference pass. (The LoRA test evaluations did save `test_labels.csv` /
`test_preds.csv` per fold, so LoRA ROC curves are available if wanted.) The per-assay boxplots
already convey per-assay discrimination.

## Reproducing

```bash
# in a pod with pandas / matplotlib / scipy / scikit-posthocs:
python make_benchmark_figures.py      # figs A, B, C, E + Nemenyi + summary
python make_adaptation_figure.py      # fig D (adaptation spectrum); auto-discovers whatever
                                       # LoRA fold results exist under
                                       # results/bioact_lora_vit_s_r224_fold*/plots/per_assay_auc.csv
# read /shared/ssd/logs/b-r-singh1/results/cv/{arm}/cv_per_assay.csv
# write figures to results/figures/
```
