# Benchmark Comparison Figures

Publication figures for the backbone bioactivity benchmark, styled after the two most important
plots of Fredin Haslum et al. (*Nature Communications* 15:3470, 2024): the per-assay ROC-AUC
boxplot (their Fig 1c) and the model comparison with Friedman + Nemenyi statistical testing
(their Fig 2a). All results are on JUMP-CP source_11, 29 assays, 6-fold CV (LoRA: single fold,
see note). Generated by `make_benchmark_figures.py` and `make_adaptation_figure.py`.

## Files

| File | What it is |
|------|-----------|
| `fig_A_per_assay_boxplot.png` | Per-assay ROC-AUC distribution, one box per backbone (29 assays) |
| `fig_B_model_comparison.png` | Frozen backbones + ResNet ranked, Friedman + Nemenyi — headline figure |
| `fig_C_resolution.png` | Resolution effect (224 vs 448) for the multi-resolution backbones |
| `fig_D_adaptation_spectrum.png` | Frozen probe -> LoRA -> fine-tuning (the adaptation spectrum) |
| `nemenyi_pvalues.csv` | Pairwise significance matrix (frozen comparison) |
| `benchmark_summary.csv` | Mean / median / std per arm |

## Results

| Regime | Model | Test ROC-AUC | Trainable params |
|--------|-------|--------------|------------------|
| Frozen probe | BiomedCLIP | 0.577 | head only |
| Frozen probe | DINOv2-Base | 0.580 | head only |
| Frozen probe | **Cell-DINO** | **0.593** | head only |
| **LoRA** | DINOv2 + LoRA | **0.608** | 0.54M (2.4%) |
| Fine-tuned | ResNet50 | 0.664 | all |

Frozen comparison Friedman: chi2 = 45.46, p = 7.4e-10 (highly significant).

Nemenyi pairwise (frozen backbones + ResNet; bold = significant at 0.05):

|-----------|---------|-------------|

| Cell-DINO vs BiomedCLIP | 0.054 | borderline (n.s.) |
| DINOv2 vs BiomedCLIP | 0.957 | no |
| **ResNet vs Cell-DINO** | **0.017** | **yes** |
| **ResNet vs DINOv2** | **<0.001** | **yes** |
| **ResNet vs BiomedCLIP** | **<0.001** | **yes** |

## Findings

1. **Domain-matched pretraining wins.** Cell-DINO (pretrained on Cell Painting) significantly beats generic ImageNet DINOv2 (Nemenyi p=0.012) — with a smaller model.
2. **"Biomedical" is not domain-matched.** BiomedCLIP is statistically indistinguishable from generic ImageNet (p=0.957) — nominal biomedical relevance does not help.
3. **Resolution is model-dependent.** It helps fine-tuned ResNet (+1.5 pts) and frozen DINOv2 (+0.9 pts, pretrained at 224) but not frozen Cell-DINO (pretrained at 128px). A frozen backbone benefits from higher resolution only when it stays close to its pretraining resolution.
4. **Cheap adaptation helps.** LoRA (2.4% of parameters trainable) reaches 0.608, above every frozen backbone, recovering ~33% of the frozen->fine-tuned gap over DINOv2.
5. **Fine-tuning remains the ceiling.** ResNet significantly beats all frozen backbones (and sits above LoRA).

## Design decisions

**1. Figure B is 224-only and frozen + ResNet, by design.** The rigorous statistical comparison
uses a single matched resolution (224) so the Friedman/Nemenyi test isolates the backbone
question from resolution. Mixing 224/448 variants would confound the two.

**2. LoRA is shown in Figure D, not Figure B.** LoRA is a single-fold result (its training is
NFS-I/O-bound at ~1 h/epoch, so a full 6-fold CV was infeasible), whereas the frozen and
fine-tuned arms are 6-fold means. To avoid mixing single-fold with 6-fold in one statistical
plot, LoRA appears in the separate adaptation-spectrum figure (Fig D), which is a regime
comparison rather than a CV significance test. This is noted directly on the figure.

**3. 448 exists only for the DINO-family backbones.** BiomedCLIP and CLIP hard-downsample input
to 224 internally and use fixed 224px positional embeddings, so a genuine 448 arm is not
possible without positional-embedding surgery and off-distribution extrapolation of a CLIP
image-text projection. They are evaluated at 224 only and excluded from Figure C.

**4. The resolution effect is a finding, not an omission** — see finding 3.

**5. Individual-assay ROC curves (the reference paper's Fig 1d) are not included for most arms.**
The pipeline saved per-assay AUC scalars, not per-sample predictions, so drawing ROC curves
would need a re-inference pass. (The LoRA test evaluation did save `test_labels.csv` /
`test_preds.csv`, so a LoRA ROC curve is available if wanted.) The per-assay boxplots already
convey per-assay discrimination.

```bash
# in a pod with pandas / matplotlib / scipy / scikit-posthocs:
python make_benchmark_figures.py      # figs A, B, C + Nemenyi + summary
python make_adaptation_figure.py      # fig D (adaptation spectrum) + LoRA per-assay CSV
# read /shared/ssd/logs/b-r-singh1/results/cv/{arm}/cv_per_assay.csv
# write figures to results/figures/
```
